Search, sort by photo count, or find a product by dropping an image.

  • Aim for 5–10 photos per SKU, from different shelves and lighting — not copies of the same crop.
  • Name SKUs brand_line_flavor_volume (example: ramy_125l_orange) so size siblings stay distinct.
  • Use Find by photo before creating a SKU, to avoid enrolling a duplicate product.
  • Front-facing full products beat tiny or half-occluded crops. Delete weak shots from the grid.
  • After adding photos here the live gallery index is updated, so the next shelf analyze can match them.
